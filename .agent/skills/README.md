# Antigravity Skills for Megarepo

This directory contains reusable skills for Google Antigravity to use when working on the megarepo AI setup repository.

## About Antigravity Skills

Skills are reusable capabilities that the AI agent can invoke to perform specific tasks. Skills complement workspace rules by providing actionable functionality.

Reference: https://antigravity.google/docs/skills

## Available Skills

### AI Development Skills
- **ai-integration.md** - Skills for integrating AI services and APIs
- **prompt-engineering.md** - Skills for designing and optimizing prompts
- **model-evaluation.md** - Skills for evaluating and testing AI models

### Code Quality Skills
- **code-review-ai.md** - Skills for reviewing AI-related code
- **security-audit.md** - Skills for auditing security in AI applications

## Usage

Skills are invoked automatically by Antigravity when relevant to the current task, or can be manually referenced in prompts. They work in conjunction with workspace rules in `.agent/rules/`.

## Skill Design Principles

- Focus on actionable tasks and specific capabilities
- Provide clear step-by-step procedures
- Include examples and best practices
- Align with repository's AI-first development approach
- Keep skills modular and reusable
